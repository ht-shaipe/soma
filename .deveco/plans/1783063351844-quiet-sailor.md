# Goal

重构 StepWizard，实现三个核心需求：
1. **步骤验证** — 每步点"下一步"时检测必填项，不通过则阻止并提示
2. **任务生命周期** — 步骤1完成后创建后端任务草稿，后续每步"下一步"自动保存当前步骤配置到后端
3. **拆分步骤** — 音频和字幕从一步拆为两步，总步骤从8步变为9步

# Scope / Non-goals

**Scope:**
- 前端 StepWizard 步骤验证逻辑
- 前端任务创建流程改造（步骤1完成后创建草稿任务）
- 前端每步保存配置到后端
- 后端新增"草稿任务"状态和"更新任务配置"API
- 步骤拆分（音频/字幕分离），总9步
- i18n 更新

**Non-goals:**
- 不改变后端 pipeline 执行逻辑（只在最终生成时才执行）
- 不实现步骤回退时恢复配置（后续需求）
- 不改变发布功能本身

## 2. 验证逻辑

在 StepWizard 中新增 `validateStep(step: number): boolean` 函数：

```typescript
function validateStep(step: number): boolean {
  switch (step) {
    case 0: // 创意意图
      if (!videoParamsStore.videoSubject.trim()) {
        ElMessage.warning(t('wizard.validate.subjectRequired'))
        return false
      }
      break
    case 1: // 文案剧情
      if (!videoParamsStore.videoScript.trim()) {
        ElMessage.warning(t('wizard.validate.scriptRequired'))
        return false
      }
      break
    case 3: // 提示词生成
      if (videoParamsStore.videoSource === 'local' && videoParamsStore.localVideoMaterials.length === 0) {
        ElMessage.warning(t('wizard.validate.localMaterialsRequired'))
        return false
      }
      break
    case 4: // 素材生成
      if (!videoParamsStore.videoTerms.trim()) {
        ElMessage.warning(t('wizard.validate.termsRequired'))
        return false
      }
      break
  }
  return true
}
```

`onNext()` 改造：
```typescript
async function onNext() {
  if (!validateStep(currentStep.value)) return
  // 步骤0完成时创建草稿任务
  if (currentStep.value === 0) {
    await createDraftTask()
  }
  // 每步保存当前配置到后端
  await saveStepConfig(currentStep.value)
  if (currentStep.value < 8) currentStep.value++
}
```

# Risks And Compatibility

- **Draft 状态新增**: 后端 TaskStatus 新增 Draft(0)，现有任务 state 都不等于 0，向后兼容
- **前端 API 新增**: 3 个新端点，不影响现有端点
- **步骤索引变更**: currentStep 数字全部后移，但模板用 v-if 匹配，无运行时风险
- **i18n key 变更**: step6-8 重新编号为 step6-9，已完成的翻译需更新
