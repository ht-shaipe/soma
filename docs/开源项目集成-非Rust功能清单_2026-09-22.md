# 开源项目集成 — 非 Rust 可实现功能清单

> 生成日期: 2026-09-22
> 来源项目: NarratoAI / creatorhub / MediaCrawler / reclip / yt-dlp
> 原则: 能用 Rust 实现的已直接集成进 soma；本文档记录**无法用 Rust 实现**、需保留 Python 生态或后续以混合架构实现的功能。

---

## 一、总览

| 来源项目 | 不可实现功能数 | 核心阻塞依赖 | 建议后续策略 |
|----------|--------------|-------------|-------------|
| NarratoAI | 6 | google-generativeai / azure-cognitiveservices-speech / faster-whisper / streamlit | Python 微服务桥接 |
| creatorhub | 14 | playwright / yt-dlp | Python 微服务桥接（Playwright 不可替代） |
| MediaCrawler | 9 | playwright / pyexecjs / xhshow / opencv / jieba / wordcloud | Python 微服务桥接 |
| reclip + yt-dlp | 0（已用 Rust 实现） | — | 已完成 |

**关键结论**: 所有不可实现功能的根本阻塞是 **5 个 Python 特有依赖**：

| 依赖 | 阻塞功能 | Rust 替代方案 | 可行性 |
|------|---------|-------------|--------|
| **playwright** | 浏览器自动化（登录/抓取/发布/监控/私信） | chromiumoxide / fantoccini | 缺少 response 拦截、持久化 profile、指纹注入 |
| **google-generativeai** | Gemini 视频上传/理解 | 无 | Google 官方 SDK，无 Rust 绑定 |
| **azure-cognitiveservices-speech** | Azure TTS 词级边界事件 | Azure REST API | REST API 不提供词级时间戳 |
| **faster-whisper** | 本地 Whisper ASR 推理 | whisper-rs | 基于 whisper.cpp，模型格式/精度不同 |
| **pyexecjs + xhshow** | 平台签名算法（抖音/知乎/小红书） | boa_engine / deno_core | JS 混淆代码兼容性存疑 |

| 属性 | 值 |
|------|-----|
| **来源文件** | `app/services/llm.py` — `gemini_video_transcription()` / `gemini_video2json()` / `_generate_response_video()` |
