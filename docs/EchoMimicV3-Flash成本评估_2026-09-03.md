| 单条 10s 口播变动成本 | **¥0.15~0.3**（480p 竖屏档，4090 按量） | 含预热摊销 + 20% 失败重试余量 |

## 一、成本口径与前提

**推理性能基准**（[Tight Studio 2026-08-23 横评](https://tight.studio/blog/open-source-talking-avatar-models/)，Modal L40S 实测）：

- 3.63s 成片（91 帧）端到端 **251.94s** —— 含模型加载、预处理、生成、解码、封装；对照同横评 SoulX-FlashTalk（首个分块 119.6s 是 TorchInductor 编译，后续块仅 3.75s/块），**冷启动编译占大头，稳态远快于此**
- 768-area 官方配置峰值显存 **33.7G**；权重缓存 **22.3GiB**；输出 480×848 @ 25fps
- 官方标称 **12G 显存**（低显存模式 app_mm.py / 量化档）；README Tips：talking head **5 步采样**、`partial_video_length` 可降到 81/65 压显存
- 音频原样保留（相关系数 0.9992）→ TTS 阶段零改动、零新增成本

**算力价格基准**（[晨涧云 vs AutoDL 2026-07 比价](https://www.mornai.cn/news/gpu/mornai-and-autodl-gpu-rent-price-comparison-2026-07/)，注意为竞品方发布，以官网现价为准）：

| 卡 | AutoDL 按量 | AutoDL 包日 | 包周 | 包月 | 等效时价(包月) |
|---|---|---|---|---|---|
| RTX 4090 24G | ¥2.19/h | ¥49/天 | ¥325/周 | ¥1,196/月 | ≈¥1.66/h |
| RTX 3090 24G | ¥1.66/h | ¥38.65 | ¥245 | ¥848 | ≈¥1.18/h |
| A100 40G | ¥3.45/h | ¥75 | ¥465 | ¥1,600 | ≈¥2.22/h |

> 官方 README 明确测试过 **RTX4090D 24G**（AutoDL 有货，通常比 4090 略便宜），CUDA ≥ 12.1。

**计费规则**（[AutoDL 官方文档](https://api.autodl.com/docs/price/)）：

- 按量计费：**开机计费、关机即停**，精确到秒；关机后数据保留（有期限）
- 数据盘免费 **50G**（另有系统盘约 30G），扩容约 ¥0.0066/日/GB ≈ **¥0.2/GB/月**，**关机也计费**
- 文件存储：20G 免费，超出 ¥0.01/GB/日
- 自定义镜像：¥0.01/GB/日（40G 环境镜像 ≈ ¥12/月）
- **无卡模式开机 ¥0.1/h**：调试代码/传文件不烧 GPU 费

## 二、单条视频的变动成本（核心账）

**GPU 时间模型**（10s 成片 = 250 帧 @25fps）：

- 横评 91 帧冷跑 252s，扣除加载/编译后稳态估 60~100s；4090 与 L40S 推理同档
- 250 帧 ≈ 91 帧的 2.2~3.7 倍窗口数 → 4090 稳态 **3~6 min/条**；若走 offload 压显存则放宽到 **3~8 min**
- 每次开机首条 +2~4 min 预热（模型加载），批量跑摊薄

**单条现金成本**（按量 ¥2.19/h = ¥0.0365/min）：

| 档位 | GPU 时间/条 | 成本/条 |
|---|---|---|
| 纯生成（不含预热） | 3~6 min | **¥0.11~0.22** |
| 批量摊销（含预热 + 20% 重试余量） | — | **¥0.15~0.3** |
| 高清档 768-area（33.7G 需 48G 卡，如 L40S/A100 40G 档） | 略快于 4090（offload 少） | ¥0.25~0.6 |

**全链路单条成本**（10s 口播）：

- GPU 生成：¥0.15~0.3
- TTS（Edge 免费 / SiliconFlow 按字符）：单条不超过几分钱
- 成片回传后云端不留档 → 无持续存储费
- **合计 ≈ ¥0.2~0.35/条**，横评口径下约 ¥1.2~2.1/分钟成片

## 三、月度成本模型（三档用量）

假设：10s 口播为主，稳态 4.5 min/条，含 20% 重试 + 预热余量 30%。

| 月用量 | 纯 GPU 需求 | 计费时长（含余量） | 按量成本 | 建议计费方式 |
|---|---|---|---|---|
| 100 条 | 7.5h | ~10h | **¥22~30** | 按量 |
| 500 条 | 37.5h | ~49h | **¥95~135** | 按量 |
| 2000 条 | 150h | ~195h | **¥380~480** | 按量或混包日（¥49/天 × 8~9 天） |

包月临界点：¥1,196/月 ÷ ¥2.19/h ≈ **545h/月**，即 7×24 常驻才回本 → **口播批量出片场景永远用按量**，除非二期上实时/直播流。

**固定小额项**：

- 存储：权重 22.3G + 运行环境压在系统盘(30G)+数据盘(50G) 免费额度内 → **¥0**；若扩容到 100G 数据盘 ≈ ¥10/月
- 环境镜像（可选，强烈建议）：免每次重装环境 ≈ **¥12/月**
- 文件存储备份：默认免费额度内 ¥0

## 四、一次性成本

**1. 开发人力（自研口径，参照 09-02 方案的改动清单）**

| 工作项 | 工时 |
|---|---|
| GPU 机环境搭建（conda + torch + 权重下载 ModelScope）+ `echomimic-service` FastAPI（submit/query/download + 队列 + 模型常驻） | 1 天 |
| soma 侧 echomimic provider（HTTP，复用 HeyGen 轮询模式）+ 配置段 | 0.5~1 天 |
| 音频预处理（16kHz wav）、参数调优（audio_guidance 1.8~2 / 步数 / 分辨率档）、样片验收 | 0.5 天 |
| 环境镜像化 + 自动关机脚本（`/usr/bin/shutdown`） | 0.25 天 |
| **合计** | **2.25~3 人天** |

**2. 调试期 GPU 现金消耗**

- 有效 GPU 时长 10~25h（装环境/试跑/联调/废片重试）≈ **¥25~60**
- 权重 ~22.3G 走 ModelScope/AutoDL 学术加速，免费
- **一次性现金合计 ≈ ¥50~100**

**3. 不花钱的部分**

- 模型/代码全 Apache 2.0，无授权费
- TTS、任务队列、字幕/BGM 合成、前端：全部复用 soma 现有，零改动

## 六、成本优化手段（操作层面，直接抄）

1. **调试不开 GPU**：改代码/传文件用无卡模式（¥0.1/h），GPU 只留给推理
2. **跑完自动关机**：`python run_flash.sh; /usr/bin/shutdown` —— 忘关机是最大的浪费源
3. **攒批出片**：soma 任务队列天然异步，集中批量跑摊薄每次开机的 2~4 min 预热
4. **保存环境镜像**：换机/重开免重装，也规避"关机后数据保留到期"风险（¥12/月）
5. **max_concurrent = 1**：防双任务挤爆显存 OOM 重试（09-02 风险清单已有）
6. **权重与数据盘控制在 50G 免费额度内**，不扩容则闲置期存储费为 0
7. 高峰期 4090 缺货备选：4090D（官方测试过）/ 3090（¥1.66/h，显存同为 24G，速度低 15~25%）/ 晨涧云等平台比价

## 七、自购 GPU 临界点（结论：现阶段不买）

- 4090 整机 ¥1.5~2.5 万（[2026-08 行情：魔改 48G 卡已站上 ¥2.5 万](https://www.mornai.cn/news/gpu/mornai-and-autodl-gpu-rent-price-comparison-2026-07/)）
- 对比按量：¥20,000 ÷ ¥2.19/h ≈ 9,100 GPU 时；对比包月 ¥1,196/月 → 回本 **14~21 个月**，且要求 7×24 满载
- 只有出现"实时交互/直播推流常驻"需求（二期 LiveAvatar/SoulX-FlashTalk 流式方向）才重新评估；批量出片场景租用恒优

## 八、隐藏成本与风险

1. **废片率**：调参期（audio_guidance/分辨率/照片质量）首批出片可能有较高重拍率 → 一次性预算已含余量，正式运行按 +20% 备
2. **数据保留期限**：按量关机后数据"保留一段时间"，长期不用要么保存镜像要么释放实例，避免到期清空 + 意外计费
3. **扩容数据盘关机也计费**：不扩容就永久 0 元；扩了就要记得缩
4. **分辨率档位决策**：480×848 竖屏（4090 档）正是抖音/视频号口播规格，先按此验收；768-area 高清档（33.7G）需 48G 卡、单条成本 ×2~3，只在客户投诉画质时再上
5. **价格波动**：本文价格为 2026-07~09 快照，AutoDL 各机房同卡价格有浮动，以官网现价为准
6. **运维投入**：日常开关机、缺货换机、监控 ≈ 每月 0.5 人天（自研无现金支出，计入人力即可）
