功能特性

三大核心能力

从 AI 脚本到成品视频，从工具箱到数字人口播，覆盖短视频创作全链路

短视频自动生成

输入主题，6 步流水线自动产出成品视频

  • AI 脚本生成（25+ LLM 提供商）
  • 需求理解与分镜（意图 → 视觉提示词 → 镜头运动）
  • 智能 TTS 合成（11 种引擎 + 声音克隆）
  • 素材自动采集（Pexels / Pixabay / Coverr）
  • AI 视频生成（智谱 / 可灵 / MiniMax）
  • FFmpeg 合成（拼接 / 转场 / 字幕 / 混音 / 水印）
  • 异步任务队列 + SQLite 持久化 + 断点续跑
  • 社交发布（TikTok / YouTube 等 12 平台）

工具箱

24 个功能点 + 7 个精选工具，即开即用

  • 功能点：流水线各步拆分为独立调用，JSON Schema 驱动动态表单
  • 视频下载：yt-dlp，支持 1000+ 站点
  • 字幕处理：SRT/VTT 转换、合并、LLM 翻译校正
  • 剪映草稿导出：视频/音频 → 剪映可编辑草稿
  • 通知推送：Bark / 钉钉 / Telegram
  • 数据导出：JSON → CSV / JSON / JSONL
  • 视频去水印：多帧梯度分析自动检测 + FFmpeg 去除
  • 抖音直连：a_bogus 签名直连 Web API
  • 图片故事：多图 + 文字 → 图片故事视频

数字人口播

一张照片 + 一段文案 → 口型同步口播视频

  • HeyGen：云端 API，付费按量
  • SadTalker：本地 CPU/GPU 推理，免费
  • EchoMimicV3-Flash：本地 GPU（≥12G），免费
  • HeyGem：Docker 三容器，免费
  • Live2D：纯 CPU 卡通数字人，零成本
  • 长文案自动分段（单段 ≤6 秒），逐段渲染后拼接
  • 内置敏感词过滤，可自定义词库
  • Live2D 支持自定义模型上传

快速上手

5 步启动

支持 Web 服务器模式与 Tauri 桌面应用模式

1

环境准备

Rust (Edition 2021) + Node.js 18+ + FFmpeg 4.0+

brew install ffmpeg  # macOS
2

获取项目

克隆仓库并复制配置模板

git clone <repo> && cd soma
cp conf/config.toml.example conf/config.toml
3

申请 API Key

至少配一个 LLM Key + 一个素材库 Key

DeepSeek Ollama 免费 Pexels 免费
4

编辑配置

编辑 conf/config.toml，填入 API Key

[app]
llm_provider = "deepseek"
deepseek_api_key = "sk-xxx"
pexels_api_keys = ["你的 Key"]
5

启动服务

Web 模式或桌面应用模式

make install && make dev      # Web
make install-tauri && make dev-tauri  # 桌面

🌐 Web 服务器模式

Actix-Web 后端 (8090) + Vue 前端 (5273)，支持远程访问

make dev

🖥️ 桌面应用模式

Tauri v2 独立窗口，无需启动后端，首启自动迁移配置

make dev-tauri
